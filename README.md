# IT-Support-Home-lab
Hands-on IT support home lab documenting Windows Server, Active Directory, networking, users, groups, and permissions.
## Overview

This repository documents my hands-on IT Support home lab, where I am developing practical skills in Windows Server administration, Active Directory, user and group management, networking, shared folders, and access permissions.

The purpose of this lab is to strengthen my practical IT Support and networking skills through hands-on configuration and troubleshooting.

## Technologies & Tools

- Windows Server
- Windows 11
- Active Directory Domain Services (AD DS)
- DNS
- VirtualBox
- Windows Networking
- File and Folder Permissions

## Lab Environment

The lab consists of:

- Windows Server configured as a Domain Controller
- Windows 11 client machine
- Active Directory domain: `LAB.local`
- Host-only network for communication between virtual machines
- NAT adapter for internet connectivity

## Projects & Tasks

### 1. Active Directory

- Configured Windows Server as a Domain Controller
- Created the `LAB.local` domain
- Created Organizational Units (OUs)
- Created and managed user accounts
- Created security groups

### 2. User & Group Management

Practised:

- Creating users
- Creating security groups
- Adding users to groups
- Organising users using Organizational Units

### 3. Shared Folders & Permissions

Configured departmental folders and practised controlling access using Windows permissions.

Example departments:

- HR
- Finance

### 4. Networking

Practised:

- Configuring IPv4 addresses
- Configuring DNS
- Testing connectivity using `ping`
- Connecting a Windows 11 client to the domain
- Troubleshooting network connectivity
