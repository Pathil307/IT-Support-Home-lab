# Active Directory Configuration

## Objective

The objective of this lab was to configure a Windows Server environment and establish an Active Directory domain for managing users, groups, and resources.

## Environment

- Windows Server
- Windows 11 client
- VirtualBox
- Active Directory Domain Services (AD DS)
- Domain: LAB.local

## Configuration

### 1. Domain Controller

Windows Server was configured as a Domain Controller using Active Directory Domain Services.

The domain was configured as:

`LAB.local`

### 2. Organizational Units

Organizational Units (OUs) were created to organise users and resources within the domain.

### 3. User Accounts

User accounts were created within Active Directory to simulate users in a business environment.

### 4. Security Groups

Security groups were created to manage access to resources based on departmental requirements.

Groups included:

- HR
- Finance

## Skills Practised

- Installing and configuring Active Directory Domain Services
- Creating a domain
- Creating Organizational Units
- Creating user accounts
- Creating security groups
- Managing users and groups
- Basic Active Directory administration

## Troubleshooting

During the lab, I practised troubleshooting issues involving domain connectivity, DNS resolution, user accounts, and access.

## Outcome

The lab successfully provided a simulated business environment where users and groups could be centrally managed through Active Directory.
