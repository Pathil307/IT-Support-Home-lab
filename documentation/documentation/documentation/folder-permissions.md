# Folder Access and Permissions

## Objective

The objective of this task was to practise configuring shared folders and managing access permissions in a simulated business environment.

## Environment

- Windows Server
- Windows 11 client
- Active Directory Domain Services (AD DS)
- Domain: `LAB.local`
- File and folder permissions

## Departmental Folders

Departmental folders were created to simulate a business environment where different departments require access to their own resources.

The folders created included:

- HR
- Finance

## Access Management

Access to the departmental folders was managed using Windows file and folder permissions.

The purpose was to practise controlling which users or groups could access specific departmental resources.

Active Directory security groups were used to represent the different departments.

For example:

- HR users → HR resources
- Finance users → Finance resources

## Permissions

The lab provided practical experience with:

- Viewing folder permissions
- Assigning permissions to users and groups
- Managing access to shared resources
- Understanding the relationship between users, groups, and permissions
- Testing access to shared folders

## Troubleshooting

Access-related issues were investigated by checking:

- User group membership
- Folder permissions
- Network connectivity
- Access to shared resources

## Skills Practised

- Windows file and folder permissions
- Access control
- Security groups
- Shared folders
- User and group management
- Basic IT troubleshooting

## Outcome

This exercise provided practical experience with managing access to departmental resources and demonstrated how user groups and file permissions can be used to control access within an organisation.
