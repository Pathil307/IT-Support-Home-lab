# User and Group Management

## Objective

The objective of this task was to practise managing users and security groups in an Active Directory environment.

## Environment

- Windows Server
- Active Directory Domain Services (AD DS)
- Domain: `LAB.local`

## User Management

User accounts were created within Active Directory to simulate employees in a business environment.

The lab involved:

- Creating user accounts
- Organising users within Organizational Units (OUs)
- Managing user account information
- Assigning users to appropriate security groups

## Security Groups

Security groups were created to organise users according to their departments and manage access to resources.

The following departmental groups were created:

- HR
- Finance

## Group Membership

Users were added to the appropriate security groups based on their simulated department.

This demonstrated how security groups can be used to manage access to shared resources within an organisation.

## Organisational Units

Organizational Units were used to organise and manage users within the Active Directory domain.

This provided a structured approach to managing users and resources.

## Skills Practised

- Creating Active Directory users
- Creating security groups
- Adding users to groups
- Managing group membership
- Organising users with Organizational Units
- Basic Active Directory administration
- Understanding role-based access management

## Outcome

This exercise provided practical experience managing users and groups within a Windows Server Active Directory environment and demonstrated how organisations can use groups and Organizational Units to manage users and resources efficiently.
